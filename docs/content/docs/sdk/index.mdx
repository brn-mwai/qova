`@qova/core` is the TypeScript SDK for the Qova protocol. Tree-shakeable, type-safe, built on viem with Zod runtime validation.

## Quick Example

```typescript
import { createQovaClient } from "@qova/core";

const client = createQovaClient({ chain: "base-sepolia" });
const score = await client.getScore("0x1234...");
```
