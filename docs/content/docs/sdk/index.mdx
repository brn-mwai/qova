[`@brnmwai/qova-core`](https://www.npmjs.com/package/@brnmwai/qova-core) is the TypeScript SDK for the Qova protocol. Tree-shakeable, type-safe, built on viem with Zod runtime validation.

[![npm](https://img.shields.io/npm/v/@brnmwai/qova-core)](https://www.npmjs.com/package/@brnmwai/qova-core)

## Quick Example

```typescript
import { createQovaClient } from "@brnmwai/qova-core";

const client = createQovaClient({ chain: "base-sepolia" });
const score = await client.getScore("0x1234...");
```
