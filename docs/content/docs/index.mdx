Qova is the **credit bureau for autonomous AI agents**. As agents transact on-chain via protocols like x402, Qova computes verifiable reputation scores (0-1000) from on-chain transaction data using **Chainlink CRE**, then writes those scores back on-chain for any protocol to consume.

Think **Equifax, but for AI**.

## Why Agent Reputation?

AI agents are increasingly autonomous - trading, bridging, paying for services. But there's no standard way to assess whether an agent is trustworthy. Qova solves this by:

- **Scoring** agents 0-1000 based on transaction history, budget compliance, and account age
- **Writing scores on-chain** so any protocol can gate access based on trust level
- **Running decentralized computation** via Chainlink CRE - no single point of failure
- **Updating in real-time** through event-driven workflows that react to every transaction

## Architecture Overview

```
Agent Platforms ──> @brnmwai/qova-core SDK ──> Smart Contracts (Base L2)
                                            │
                                    Chainlink CRE Network
                                    (4 scoring workflows)
                                            │
                                    Score Consumers
                                    (DeFi, Insurance, Lending)
```

The protocol has six packages in a Turborepo monorepo:

| Package | Purpose |
|:--------|:--------|
| `contracts/` | Solidity smart contracts for reputation, transactions, budgets |
| `sdk/` | TypeScript SDK wrapping all contract interactions |
| `api/` | REST API with 21 endpoints on Hono + Bun |
| `dashboard/` | Next.js 15 real-time analytics dashboard |
| `cre/` | 4 Chainlink CRE decentralized scoring workflows |
| `integrations/` | Framework plugins (LangGraph, CrewAI, n8n) |

## npm Package

The SDK is published on npm as [`@brnmwai/qova-core`](https://www.npmjs.com/package/@brnmwai/qova-core):

```bash
bun add @brnmwai/qova-core viem
```

```typescript
import { createQovaClient } from "@brnmwai/qova-core";

const client = createQovaClient({ chain: "base-sepolia" });
const score = await client.getScore("0xAgentAddress...");
// => 750 (grade: BBB)
```
