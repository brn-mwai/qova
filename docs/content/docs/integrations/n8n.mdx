Visual workflow nodes for n8n that add reputation checkpoints.

## Nodes

| Node | Type | Description |
|:-----|:-----|:-----------|
| **Qova Score Check** | Action | Read score and gate workflow |
| **Qova Record Transaction** | Action | Record a transaction |
| **Qova Budget Check** | Action | Verify budget compliance |
| **Qova Score Trigger** | Trigger | Fire on score changes |

## Features

- Visual workflow builder integration
- Conditional branching based on scores
- Webhook triggers for score changes
- No code required for basic flows
