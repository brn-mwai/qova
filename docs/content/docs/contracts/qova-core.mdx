Facade contract that coordinates operations across ReputationRegistry, TransactionValidator, and BudgetEnforcer.

## Functions

| Function | Access | Description |
|:---------|:-------|:-----------|
| `executeAgentAction(address, bytes32, uint256, uint8)` | Public | Record tx + check budget in one call |

## Events

```solidity
event AgentActionExecuted(address indexed agent, bytes32 indexed txHash, uint256 amount, uint8 txType);
```

## Access Control

QovaCore holds privileged roles on all three core contracts:

| Role | Contract |
|:-----|:---------|
| `UPDATER_ROLE` | ReputationRegistry |
| `RECORDER_ROLE` | TransactionValidator |
| `BUDGET_MANAGER_ROLE` | BudgetEnforcer |
