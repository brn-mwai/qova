## Verify Portal (`/verify`)

Run 8-check verification on any agent address. View verification history and download credit reports.

## Credit Report (`/verify/report/[address]`)

Detailed credit report including:

- Full score breakdown with factor weights
- Transaction history summary
- Budget compliance metrics
- All 8 verification checks with pass/fail
- Printable format
