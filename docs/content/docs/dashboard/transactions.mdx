## Transaction Log (`/transactions`)

Full transaction log with filters for agent, type, date range, and chain. Currency labels adapt automatically when switching chains (ETH on Base, USDC.e on SKALE Base). Agents transact in bridged stablecoins (USDC.e, USDT) and WETH on SKALE Base.

## Recording Transactions

Record new transactions directly from the dashboard:

1. Select the agent
2. Enter transaction hash and amount
3. Choose transaction type
4. Submit

Explorer links are generated per-chain automatically.
