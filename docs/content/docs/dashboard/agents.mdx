## Agent List (`/agents`)

View all registered agents with scores, grades, activity, and transaction counts. Filter by chain, grade, and status.

## Agent Detail (`/agents/[address]`)

Deep dive into a single agent:

- **Score history** - Chart showing score changes over time
- **Transaction log** - All recorded transactions
- **Budget utilization** - Daily and monthly spending
- **Verification status** - Latest verification result
- **Credit report link** - Downloadable report

## Register Agent

Register new agents directly from the dashboard. Connect your wallet and submit the agent address.
