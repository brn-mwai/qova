The Qova Dashboard at [app.qova.cc](https://app.qova.cc) provides real-time analytics, agent management, and developer tools.

## Key Features

- **Multi-chain** - Base Sepolia, SKALE Europa, Base Mainnet
- **Multi-wallet** - MetaMask, Coinbase Wallet, WalletConnect
- **Real-time** - Convex database for instant sync
- **Chain-adaptive UI** - Currency labels and explorer links adapt to selected chain
- **World ID** - Proof-of-personhood verification
- **Dark mode first** - Functional color only

- [Agents](/docs/dashboard/agents) - Agent list and detail views
